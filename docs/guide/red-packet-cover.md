# 微信红包封面小程序开发规划

本文面向基于 Wot Starter v2 开发「微信红包封面发布」小程序的场景，适合作为新仓库立项时的产品与技术拆解。

## 目标定位

- 面向品牌、设计师或运营人员集中发布微信红包封面。
- 用户可以浏览封面、查看领取条件、复制或跳转领取链接。
- 管理端维护封面素材、上下架状态、领取规则与数据统计。
- 首期以微信小程序为主，优先保证移动端体验与微信生态合规。

## 推荐仓库方案

建议另开业务仓库，避免把行业业务逻辑放进通用 starter 模板：

```bash
git clone https://github.com/wot-ui/wot-starter.git red-packet-cover-miniapp
cd red-packet-cover-miniapp
pnpm install
```

新仓库可按以下方向初始化：

- 更新 `package.json` 中的 `name` 与项目描述。
- 配置 `manifest.config.ts` 的微信小程序 appid、名称与权限。
- 保留 Wot Starter v2 的 Vue 3、TypeScript、Wot UI、UnoCSS、Alova、Pinia 与 `build:mp-weixin` 工作流。
- 根据业务新增接口模块、状态模块和页面分包，不反向污染 starter 模板。

## 核心页面

| 页面 | 说明 | 推荐组件 |
| --- | --- | --- |
| 首页 | 展示活动 banner、热门封面、新品封面与分类入口 | `wd-swiper`、`wd-card`、`wd-grid` |
| 封面列表 | 支持分类、标签、状态筛选与分页加载 | `wd-tabs`、`wd-tag`、`wd-loadmore` |
| 封面详情 | 展示封面大图、领取说明、剩余数量、有效期和领取入口 | `wd-img`、`wd-cell`、`wd-button` |
| 领取记录 | 展示用户已领取、已失效、待领取的封面 | `wd-status-tip`、`wd-cell-group` |
| 运营管理 | 维护封面上下架、库存、领取口令、活动时间 | `wd-form`、`wd-upload`、`wd-datetime-picker` |
| 关于/规则 | 展示平台说明、领取规则、客服与合规声明 | `wd-notice-bar`、`wd-collapse` |

## 数据模型

首期可以围绕以下实体设计接口：

- `Cover`：封面标题、封面图、品牌方、分类、标签、状态、领取链接、有效期。
- `Campaign`：活动标题、开始时间、结束时间、投放位置、优先级。
- `ClaimRule`：登录要求、领取次数限制、库存、白名单或口令规则。
- `ClaimRecord`：用户标识、封面 ID、领取时间、领取状态。
- `AdminUser`：运营人员角色、权限范围与操作日志。

## 技术拆解

### 前端结构

```text
src/

  pages/
    index/index.vue
    cover/list.vue
    cover/detail.vue
    record/index.vue
    admin/index.vue
  stores/
    cover.ts
    user.ts
  types/
    cover.ts
```

### 接口与状态

- 使用 Alova 封装封面列表、详情、领取记录与管理接口。
- 使用 Pinia 保存用户登录态、筛选条件和最近浏览记录。
- 列表接口使用分页游标或页码，避免一次性拉取大量封面。
- 领取入口需要服务端校验库存、频控和活动有效期，前端只做展示与交互提示。

### 微信能力

- 使用微信登录能力换取业务用户标识。
- 使用 `button` 的开放能力或客服能力承接咨询入口。
- 领取红包封面必须遵守微信红包封面平台规则，前端只展示已通过审核的封面与领取方式。
- 需要在微信公众平台配置合法域名、业务域名与隐私协议。

## 视觉与交互建议

- 首页首屏突出节日氛围、品牌信息和主领取按钮。
- 封面卡片保持封面预览、库存状态和领取标签三要素。
- 详情页使用醒目的「立即领取」按钮，并在按钮附近展示有效期与限制条件。
- 已抢光、未开始、已过期等状态要有明确空态和禁用态。
- 管理端不建议放在普通用户主路径中，可通过角色或独立入口控制。

## 里程碑

1. **MVP**：首页、列表、详情、领取跳转、基础接口联调。
2. **运营能力**：活动配置、上下架、库存、领取记录。
3. **增长能力**：分享海报、订阅消息、活动专题页。
4. **数据能力**：访问量、点击量、领取转化、封面热度排行。
5. **合规加固**：隐私协议、内容审核、接口鉴权、操作日志。

## 验收清单

- `pnpm lint` 通过。
- `pnpm type-check` 通过或确认第三方 uni module 类型问题不影响本次业务代码。
- `pnpm build:mp-weixin` 可以生成微信小程序产物。
- 真机验证首页、列表、详情、领取入口、分享路径和异常状态。
- 微信公众平台完成 appid、合法域名、隐私协议和类目配置。
